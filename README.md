# STM32 嵌入式开发项目集

## 📌 项目一：转盘抽奖系统设计
**技术栈**：C语言、STM32F103ZE、Keil uVision5、随机数算法

**项目描述**：
基于STM32单片机开发转盘抽奖节点控制逻辑，涵盖底层固件开发与硬件联调。

**核心贡献与成果**：
1. 使用随机数算法实现抽奖概率的动态控制，保证抽奖公平性。
2. 完成软件仿真与逻辑验证，接入实际开发板进行硬件联调。
3. 解决软硬件接口调试中的稳定性问题，具备完整嵌入式开发闭环经验。

---

## 📌 项目二：数字电子锁电路设计与实现
**技术栈**：Multisim、Altium Designer (PCB Layout)、硬件焊接与调试

**项目描述**：
基于数字电路原理，独立完成电子锁的仿真、原理图绘制、PCB打样与实物调试。

**核心贡献与成果**：
1. 使用Multisim完成电路原理图仿真与信号传输验证。
2. 基于Altium Designer进行PCB Layout与封装设计。
3. 负责样机焊接与功能调试，排查并解决电路稳定性问题，实现密码锁判定逻辑。
